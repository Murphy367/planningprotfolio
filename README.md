# Murphy Tang — Fashion Planning Portfolio

Interactive portfolio of Fashion Business Management coursework at FIT (assortment planning & buying, product development, trend forecasting, marketing, import buying and CAD design).

Live site: https://murphy367.github.io/planningprotfolio/

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `assets/` — full-size project boards
- `thumbs/` — smaller images used in the grid
